# spt_qa_database
Database to store QA outputs from DRP as well as observation conditions.

## Installation

```sh
pip install .          # library: sqlalchemy and psycopg (3)
pip install -e '.[dev]'  # plus alembic, pytest, pandas, ...
```

Connect with a `postgresql+psycopg://user@host:port/dbname` URL. SQLAlchemy 2.1
also accepts plain `postgresql://` for psycopg 3, but older versions map that to
psycopg2, which is no longer installed.

## Schema diagram

`diagrams/schema.pdf` is the ER diagram of the models in `python/qadb/models.py`.
It is regenerated by the *Schema diagram* GitHub Action whenever `models.py`
changes on `main`: the Action creates the schema in a throwaway Postgres, draws
it with [SchemaCrawler](https://www.schemacrawler.com/) and commits the PDF.
Don't edit the PDF by hand; to redraw it without a models change, run the
workflow from the Actions tab.
